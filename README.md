# CarreiraFlow 🚀
## Editor e Gerador Profissional de Currículos e Cartas de Apresentação

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Status](https://img.shields.io/badge/status-em_desenvolvimento-green.svg)

O **CarreiraFlow** é uma plataforma gratuita para criação, edição e geração de currículos profissionais (CVs) e cartas de apresentação, desenvolvida com o objetivo de facilitar o acesso a documentos profissionais de qualidade para estudantes, profissionais e candidatos ao mercado de trabalho.

---

# 📌 Sobre o Projeto

Nos últimos tempos, tornou-se cada vez mais comum encontrar pessoas com dificuldades na criação ou atualização dos seus currículos.

Muitos estudantes, profissionais e candidatos procuram plataformas online para criar os seus CVs, mas frequentemente enfrentam limitações: modelos pagos, bloqueios na exportação para PDF, funcionalidades premium obrigatórias ou custos inesperados no momento mais importante — quando precisam realmente do documento.

Foi a partir dessa necessidade que nasceu o **CarreiraFlow**.

A ideia surgiu com o objetivo de criar uma ferramenta simples, gratuita e acessível, permitindo que qualquer pessoa consiga criar um currículo moderno, profissional e personalizado sem depender de serviços pagos.

O projeto pretende ajudar:

- 🎓 Estudantes em busca do primeiro emprego ou estágio;
- 💼 Profissionais que precisam atualizar o seu currículo;
- 👥 Pessoas que possuem dificuldades com ferramentas de edição;
- 🌍 Comunidades que precisam de soluções gratuitas e acessíveis.

---

# 🎯 Objetivo

O principal objetivo do CarreiraFlow é democratizar a criação de documentos profissionais, oferecendo uma experiência simples e intuitiva para:

- Criar currículos personalizados;
- Editar informações profissionais;
- Escolher diferentes modelos visuais;
- Gerar documentos prontos para candidatura;
- Criar cartas de apresentação profissionais.

---

# ✨ Funcionalidades Atuais

## 📄 Editor de Currículo

- Criação e edição completa de currículos;
- Modelos profissionais pré-definidos;
- Personalização visual;
- Organização das informações pessoais e profissionais;
- Pré-visualização do documento.

## 📨 Carta de Apresentação

- Editor integrado de cartas de apresentação;
- Estrutura profissional;
- Personalização do conteúdo;
- Preparação para diferentes oportunidades profissionais.

## 🎨 Personalização

- Alteração de temas visuais;
- Diferentes estilos de apresentação;
- Modelos adaptáveis.

## 💾 Gestão de Dados

- Salvamento automático de rascunhos;
- Backup dos dados;
- Importação de informações;
- Continuidade da edição sem perder progresso.

## 📤 Exportação

- Geração de documentos em formato PDF;
- Preparação do currículo para utilização profissional.
